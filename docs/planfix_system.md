## Что такое объекты в Planfix

В Planfix объекты — это **шаблоны карточек** (Task Templates), из которых создаются конкретные экземпляры-сущности: сделки, инвойсы, расходы, задачи. Каждый шаблон идентифицируется `objectId`.

---

## Карта сущностей

```
Новый клиент (лид)
    │
    │  (конвертация)
    ▼
Текущие клиенты (проект/сделка)
    ├── Invoice (доход / счёт)
    │       ├── Прочие поставщики Конфеты  (расход нал)
    │       └── Прочие поставщики безнал   (расход безнал)
    │
    └── Проекты  (сущность-связка)
            └── Рабочая задача

Отпуск  (независимая сущность)
```

## Сущности (шаблоны задач)

### Текущие клиенты
| Поле        | Значение        |
|-------------|-----------------|
| objectId    | `4966423`       |
| Тип         | Сделка / Проект |
| Роль        | Основная сущность системы. Представляет активного клиента или текущий проект/сделку. |

**Связи:**

## Финансовая логика

```
Текущие клиенты
    └── Invoice (выставленный клиенту счёт = ДОХОД)
            ├── Прочие поставщики Конфеты (РАСХОД нал)
            └── Прочие поставщики безнал  (РАСХОД безнал)

Маржа по проекту ≈ Invoice − Σ Расходов
```

## Миграция из Megaplan

| Megaplan              | Planfix                              | Статус     |
|-----------------------|--------------------------------------|------------|
| Contractor (компания) | Контакт компании (isCompany=true)    | В работе   |
| Contractor (ИП)       | Контакт компании (isCompany=true)    | В работе   |
| Contact (физлицо)     | Контакт персоны (isCompany=false)    | В работе   |
| Payer (реквизиты)     | Кастомные поля / description компании| В работе   |
| Сделки                | Текущие клиенты (objectId=4966423)   | Не начато  |
| Документы / файлы     | Файлы в Planfix                      | Не начато  |
