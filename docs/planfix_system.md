## Что такое объекты в Planfix

В Planfix объекты — это **шаблоны задач** (Task Templates), из которых создаются конкретные экземпляры-сущности: сделки, инвойсы, расходы, задачи. Каждый шаблон идентифицируется числовым `id`. Администратор шаблонов — **Алина Гламаздина** (`user:1`).

---

## Карта сущностей

```
Новый клиент (лид)  id=4519
    │
    │  (конвертация)
    ▼
Текущие клиенты (проект/сделка)  id=11
    ├── Invoice (доход / счёт)  id=21
    │       ├── Прочие поставщики Конфеты  (расход нал)   id=15
    │       └── Прочие поставщики безнал  (расход безнал) id=7691
    │
    └── Проекты  (сущность-связка)  id=уточнить
            └── Рабочая задача  id=7824

Отпуск  (независимая HR-сущность)  id=7959
Стандартный  (системный шаблон по умолчанию)  id=1
```

|--------------------|---------------------------------|
| **id**             | `11`                            |
| Тип                | Сделка / Проект                 |
| Начальный статус   | `1` — Новая (`#00b4b4`)         |

| Участники          | Все сотрудники (группа `23039`) |
| Наблюдатели        | Все сотрудники (группа `23039`) |
| Проверка результата| Да (`resultChecking: true`)     |

**Роль:** Основная сущность системы. Представляет активного клиента или текущий проект/сделку. Аналог «сделки» в CRM.

- К ней прикрепляется **Invoice** (доходы)

**Кастомные поля:** см. [`docs/templates/11_tekushchie_klienty.md`](templates/11_tekushchie_klienty.md) | JSON-конфиг: `config/planfix_fields/template_11.json`

**Поля шаблона** (из decoded description):

| Поле в шаблоне          | Переменная Planfix                     |
|-------------------------|----------------------------------------|
| Клиент (BILL TO)        | `{{Task.Counterparty}}`                |
| Адрес клиента           | `{{Task.Counterparty.Address}}`        |
| Номер инвойса           | `{{Task.Invoice Number}}`              |
| Дата инвойса            | `{{Task.Invoice Date}}`                |
| Срок оплаты             | `{{Task.Payment due}}`                 |
| Скидка (%)              | `{{Task.DISCOUNT}}`                    |
| Сумма скидки            | `{{Task.Discount Amount}}`             |
| Итого                   | `{{Task.INVOICE TOTAL}}`               |
| Примечания / условия    | `{{Task.Notes / Payment terms}}`       |

**Data tags (строки таблицы позиций):**

| Data tag                         | Описание              |
|----------------------------------|-----------------------|
| `Data tag.Item/Service.Название` | Наименование позиции  |
| `Data tag.Item/Service.Rate`     | Цена за единицу       |
| `Data tag.Item/Service.Quantity` | Количество            |
| `Data tag.Item/Service.Amount`   | Сумма позиции         |
| `Data tag.TAX.Tax Type.Tax Name` | Тип налога            |
| `Data tag.TAX.TAX`               | Сумма налога          |

## Финансовая логика

```
Текущие клиенты (id=11)
    └── Invoice (id=21)  ← ДОХОД, статус "Send Invoice"
            ├── Прочие поставщики Конфеты (id=15)   ← РАСХОД нал,   статус "К оплате"
            └── Прочие поставщики безнал  (id=7691)  ← РАСХОД безнал, статус "К оплате"

Маржа по проекту ≈ INVOICE TOTAL − Σ(расходы нал + расходы безнал)
```

Расходы обрабатываются двумя ответственными: Алина Гламаздина + Екатерина Долгова.

## Миграция из Megaplan

| Megaplan              | Planfix                                   | Статус     |
|-----------------------|-------------------------------------------|------------|
| Contractor (компания) | Контакт компании (`isCompany=true`)       | В работе   |
| Contractor (ИП)       | Контакт компании (`isCompany=true`)       | В работе   |
| Contact (физлицо)     | Контакт персоны (`isCompany=false`)       | В работе   |
| Payer (реквизиты)     | Кастомные поля / description компании     | В работе   |
| Сделки                | Текущие клиенты (`id=11`)                 | Не начато  |
| Документы / файлы     | Файлы в Planfix                           | Не начато  |
